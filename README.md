# Gian Carlo Cariño — AI Systems Engineer

A concise portfolio for an AI systems engineer working across agent systems, revenue automation, integrations, QA, security, and production infrastructure.

## Highlights

- Responsive frosted editorial interface
- Semantic HTML and accessible navigation
- Per-page SEO metadata
- Schema.org `Person` structured data
- Optimized, locally bundled artwork

## Run locally

```sh
git clone https://github.com/wizgcc-AI/giancarlo-ai-systems-portfolio.git
cd giancarlo-ai-systems-portfolio
bun install
bun run dev
```

## Built with

- React 19
- TanStack Start
- TypeScript
- Tailwind CSS 4
- Lucide React
